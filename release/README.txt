stabplayer — 手持视频实时去抖播放器(Windows)
============================================

一、怎么用
  1. 把整个 stabplayer 文件夹(含 _internal)放到本机任意位置;只拷 exe 不行。
  2. 双击 stabplayer.exe 会弹出选文件框;或把视频文件拖到 stabplayer.exe 上;
     或命令行:  stabplayer.exe 视频文件 [选项]
     播放中也可以把新视频拖进窗口直接切换。
  3. 开播前会先缓冲最多 10 秒的内容(4K 约 4 秒就能填满),用来保证去抖质量;进度在窗口里显示。
  4. 电脑上不需要装 Python 或别的东西。显卡只要支持 OpenGL 3.3(NVIDIA / AMD / Intel 核显都行)。

二、画面输出规则
  - 输出始终是完整画面:不裁切、不放大。去抖把画面移开后露出的边缘缺口,用前后相邻帧(±4/±8/±16 帧内)补上;
    补不上的极少数角落像素用边缘延伸兜底。按 X 可以开关补缺口。
  - 按输出分辨率等比缩放:4K 屏上 1:1;2560 宽的屏约 2/3;1920 宽的屏 1/2。
    窗口大小决定缩放比例,缩小时按画质优先的规则(mip + 锐度补偿)取样,放大/1:1 时用 Catmull-Rom 双三次。
  - 按 1 进入 1:1 原生像素模式:窗口里每个像素对应视频一个像素(窗口比视频小就显示画面正中央的一块)。
  - 去抖变换、缩放、色彩转换在一个着色器里一次完成,只有一次重采样;暗部渐变前加 ±0.5 LSB 的静态抖动,避免色带。
  - 默认窗口 = 屏幕工作区内同比例的最大窗口(不超过视频原分辨率)。

三、去抖强度
  五档预设(按 [ ] 切换,默认第 4 档 stronger):
    1 light   σ0.15s   校正范围 1.04
    2 standard σ0.25s  校正范围 1.06
    3 strong  σ0.40s   校正范围 1.10
    4 stronger σ0.60s  校正范围 1.15
    5 max     σ1.00s   校正范围 1.25
  「校正范围」是允许的最大校正量(≈ 画面宽 × (1-1/倍数)/2 像素),画面本身不裁切。
  越强越平稳,但对镜头真实摇移的跟随越慢;按 - = 可单独微调校正范围。
  按 S 对比开/关去抖,按 C 左右分屏对比(左原片、右去抖)。

四、资源策略
  默认把资源用满、画质开到最高,只守一条底线:不让内存耗尽(给系统留至少 2GB 或总内存的 25%)。
  - 帧缓冲:目标 10 秒内容(4K 约 3.7GB 内存);内存不足时自动减少,最少 45 帧。--prebuffer / --buffer-gb 可改。
  - 补缺口的相邻帧纹理池:4K 约 410MB 显存(1080p 约 100MB);分配失败时只退化为边缘延伸。
  - 解码和运动分析用满 CPU 核,线程优先级降一档,界面/渲染/音频优先。
  - 音频设备停摆(蓝牙/被独占等)时,时钟自动退回系统时钟,画面照常播放。

五、快捷键
  空格 播放/暂停          ← → 快退/快进 5 秒(Shift 30 秒)
  S 去抖开关              C 分屏对比
  [ ] 预设弱/强           - = 校正范围小/大
  X 相邻帧补缺口开关      1 1:1 原生像素      G 渲染质量(high/normal/fast)
  ↑ ↓ 音量   M 静音       , . 音画同步微调(±10ms)
  D 切换音频输出设备(听不到声音时用)
  F / F11 / Alt+Enter / 双击画面   全屏(Esc 退出全屏;全屏下鼠标闲置 2.5 秒自动隐藏)
  P 截图(存到当前工作目录, 双击/拖放启动时即 exe 所在目录)   I 显示统计   H 帮助   Q / Esc 退出
  快捷键没反应时:程序已关闭输入法对窗口的介入,中文输入法下字母键也能用;
  仍然没反应请把日志发来(日志里会记录收到的每个按键)。

六、常用命令行选项(stabplayer.exe --help 看全部)
  --preset N        强度预设 1~5            --mode stab|orig|split   起始显示模式
  --no-fill         关闭相邻帧补缺口        --quality high|normal|fast
  --size 1600x900   初始窗口大小            --fullscreen
  --prebuffer 秒    开播前缓冲时长          --buffer-gb GB          缓冲内存预算
  --mute            启动即静音              --list-audio / --audio-device 名称
  --av-offset 毫秒  音画微调(正值=画面晚于声音)

七、日志与自检(出问题时发给开发者)
  - 每次运行都在 exe 同目录写 stabplayer.log(目录不可写时写到临时目录):环境、显卡、音频、逐秒帧率/丢帧/耗时统计、
    事件、异常栈。画面卡顿、闪退、没声音,把这个文件发过来即可。
  - 自检:把视频拖到 selftest.bat 上运行(或 stabplayer.exe --selftest 视频文件),不开窗口,
    测本机解码、GL 上传、绘制、音频性能并写入日志。注意自检会通过默认声卡播放约 0.5 秒音频。

八、已知限制
  - 只做整幅相似变换(平移+旋转+缩放),不处理果冻效应/镜头畸变;画面里没有纹理或大面积运动物体占主导时运动估计会失效
    (估计失败的那些帧按「相机没动」处理,去抖效果减弱,但不会乱动画面)。
  - 相邻帧补出的缺口来自其他时刻:静态背景处无缝;缺口处有快速运动的物体或亮度剧变(如镜头扫向暗处)时,
    补出的窄带与主画面之间可能有可见接缝。四角极少数像素用边缘延伸兜底。
  - HDR 视频不做色调映射;只测过 8-bit / 10-bit 4:2:0。
  - exe 没有数字签名,Windows SmartScreen 或杀毒软件可能提示/误报,需要手动放行。
